# Nano Keyboard Shortcuts for Faster Navigation and Editing

Here are some useful **nano keyboard shortcuts** that can speed up your navigation and editing:

## Basic Navigation
- **`Ctrl + A`**: Move the cursor to the beginning of the line.
- **`Ctrl + E`**: Move the cursor to the end of the line.
- **`Ctrl + Y`**: Scroll up one page.
- **`Ctrl + V`**: Scroll down one page.
- **`Ctrl + _`**: Go to a specific line and column (e.g., `Ctrl + _`, then enter `10,20` for line 10, column 20).
- **`Alt + /`**: Move to the end of the file.
- **`Alt + \`**: Move to the beginning of the file.

## Editing Text
- **`Ctrl + K`**: Cut the current line and save it to the clipboard.
- **`Ctrl + U`**: Paste the line from the clipboard.
- **`Ctrl + J`**: Justify the current paragraph (aligns text).
- **`Ctrl + 6`** or **`Alt + A`**: Start selecting text. Use the arrow keys to highlight.
- **`Ctrl + Shift + -`**: Insert a comment (if syntax highlighting is enabled).

## Searching
- **`Ctrl + W`**: Search for text.
- **`Ctrl + Q`**: Cancel the search or a current command.
- **`Alt + W`**: Repeat the last search.
  
## File Management
- **`Ctrl + O`**: Save the file without exiting.
- **`Ctrl + X`**: Exit nano (prompts to save if there are unsaved changes).
- **`Ctrl + R`**: Insert another file at the cursor position.

## Working with Multiple Buffers (if enabled)
- **`Ctrl + R`**: Open a new file as a buffer within the same nano session.
- **`Ctrl + X`**: Close the current buffer.
  
Using these shortcuts, you can navigate, edit, and manage files faster in **nano**!
